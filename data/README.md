# Airport Codes and Filetypes Data

The data is a list of airport codes and their corresponding cities, countries and other information. It's collected by Switcheristic Telecoms and stored ina [Google spreadsheet](https://docs.google.com/spreadsheets/d/1-e0R5g0bxHR13W1JrfYqPf33qkssX3z_Sjg43osodFU/edit#gid=352282743) and saved as a CSV file for data cleaning and analysis.
